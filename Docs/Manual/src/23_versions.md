# Version history {#ch23}

The version of an installed FeelKit is shown in **Edit** > **Plugins**, on its entry. Both editions share one version number.

## 1.0.0 {#ch23_100}

First release, for Unreal Engine 5.6, 5.7 and 5.8, built and tested on Windows.

- **FeelKit Lite:** the recipe editor, 12 steps, **Play Feel** and its target nodes, the full comfort layer with its presets, flash limiter and comfort menu, the Feel Switch, and 11 library recipes.
- **FeelKit Pro:** everything in Lite, plus 25 more steps, parameters, accumulators and sustained recipes, Feel Maps and events, animation notifies, the Feel Trigger, Feel Input and Feel Replication components, the GAS add-on, the Recipe Browser with 38 library recipes, the FeelKit Debugger, recent plays, Capture GIF, sound waveforms and tracks from sound, JSON import and export, the Comfort Audit, and the recipes of the demo levels.
